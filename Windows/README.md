# Klarfolio für Windows

Dieses Verzeichnis ist der Einstiegspunkt für die geplante native Windows-App im gemeinsamen Klarfolio-Repository.

Aktueller Stand: Architektur- und Spike-Phase. Es ist noch kein ausführbares Windows-Projekt eingecheckt, weil PDF-Engine, Lizenzmodell und Zielarchitektur zuerst anhand realer Fixtures entschieden werden.

Verbindliche Planung: [`../docs/internal/windows-roadmap.md`](../docs/internal/windows-roadmap.md)

Die erste technische Lieferung wird eine kleine Windows-App für Öffnen, Rendern, Textsuche, eine Annotation und verlustfreies Speichern sein. Erst nach diesem Nachweis beginnt die MVP-Parität zur macOS-App.
